Requirements

Windows 10/11 (64-bit), a microphone for voice, about 400 MB free disk. For Urdu speech add an Urdu voice in Windows Settings → Time & language → Speech.

FAQ

The ghost does not hear my claps.

Open Settings → Fix problems → Mic test and raise Sensitivity. Check Windows Settings → Privacy → Microphone.

It shows text but does not speak Urdu.

Add an Urdu voice in Windows Settings → Time & language → Speech. Without one the ghost shows text only.

My antivirus complains.

Unsigned apps sometimes get false alarms. The source is open and the app makes no network connections.

How do I quit or uninstall?

Tray icon → Quit. To uninstall, delete the folder (and the Desktop shortcut if you made one).
